# ACE/TAO C++17 modernization ledger

Local working administration only.  This file is intentionally untracked and
must not be added to modernization commits.  Update it after every pushed
batch, and read the relevant directory entry before starting another sweep.

## Status key

- `initial pass complete`: The listed directory has received the agreed
  modernization review.  A later pass may still add a newly requested cleanup.
- `partial`: Only the named subdirectories or interface family have been
  completed.  Do not infer that sibling code was reviewed.
- `generated`: Do not edit directly; change the generator and validate output.

## Common completed tasks

Unless an entry narrows the scope, an initial pass covers safe C++17 changes:

- `override` only after verifying the immediate base and conditional variants.
- `= default` for empty special members and `= delete` for unwanted copying
  and moving, keeping declarations on one line.
- `explicit` for verified single-argument constructors that are not intended
  to support implicit conversion; preserve established var/out and conversion
  wrapper semantics.
- Internal `typedef` to `using`, pointer `0`/`NULL` to `nullptr`, and local
  scalar constants to `constexpr` where linkage/ODR use is safe.
- East-side `const`, without altering public ABI or generated/imported files.
